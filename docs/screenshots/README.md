# Real application screenshots

Captured from the running application with the built-in, isolated demo kitchen. No real household data, external stock photos or generated UI mockups are used. The landing page includes an explicitly labelled illustrative preview.

- `landing.png`: public introduction, desktop width.
- `dashboard.png`: authenticated kitchen dashboard, desktop width.
- `recipes.png`: pantry readiness matching in the recipe notebook.
- `mobile.png`: the dashboard at 390 × 844 CSS pixels.

To reproduce, run the quick start, create a demo using `seed_demo`, sign in, and capture these pages. Dates are relative to when the demo was seeded, so they will differ between runs. Credentials and the demo database are deliberately not committed.
